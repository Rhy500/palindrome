# Palindrome Checker

A simple web application designed to check whether a word, phrase, or number is a **palindrome**.

> **What is a Palindrome?**  
> A palindrome is a word, phrase, number, or sequence of characters that reads the same backward as forward (e.g., *katak*, *malam*, *12321*).

## 🛠️ Built With

This project is built using core web technologies:
- **HTML5** (`index.html`): Markup structure for the input form, buttons, and result display.
- **CSS3** (`styles.css`): Styling, layout, and visual presentation[cite: 4].
- **JavaScript** (`script.js`): Logic to process text, reverse strings, and evaluate palindrome conditions[cite: 4].

## 💡 How It Works

1. The user enters text or numbers into the input field.
2. The JavaScript logic cleans the string (removes special characters, spaces, and converts all letters to lowercase).
3. The cleaned text is compared with its reversed version:
   - If `original === reversed`, it displays a confirmation that the text **is a palindrome**.
   - Otherwise, it indicates that the text **is not a palindrome**.

## 🚀 How to Run

Since this is a client-side web application, no installation or server configuration is required.

### Method 1: Direct File Opening
1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Double-click `index.html` to open the app directly in your web browser[cite: 4].

### Method 2: Using VS Code Live Server (Recommended)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html` and select **Open with Live Server**[cite: 4].
